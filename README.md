# Daily Quote Generator

A simple, responsive web page that displays an inspirational quote and allows users to generate a new one with a click. Built with HTML, CSS, and vanilla JavaScript.

## Features

*   Displays a random quote on page load.
*   Button to generate a new random quote.
*   Responsive design for various screen sizes.

## How to Run

1.  **Clone the repository (or copy files):**
    If you're using `git`:
    ```bash
    git clone <repository-url>
    cd daily-quote-generator
    ```
    Otherwise, simply create a folder and place `index.html`, `style.css`, and `script.js` inside it.

2.  **Open `index.html`:**
    Navigate to the project directory and open the `index.html` file in your web browser. You can usually do this by double-clicking the file.

That's it! The page will load, and you can start generating new quotes.
